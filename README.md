# 개인 점성술사

Claude Code 위에서 돌아가는 개인 점성술사 템플릿이다. 서양 점성술 출생차트와 사주팔자 데이터를 미리 넣어두면, 그걸 근거로 질문에 답해준다. 포크해서 자기 데이터로 채우면 누구나 자기만의 버전으로 쓸 수 있다.

이런 걸 왜 만들었냐면, 점성술 상담을 받을 때마다 생년월일시·출생지·지난 리딩 내용 같은 배경 정보를 매번 다시 설명하는 게 은근히 귀찮아서다. 로컬 파일에 한 번 적어두면 그다음부턴 반복 설명 없이 바로 본론으로 들어갈 수 있다.

몇 가지 원칙을 갖고 만들었다:
- **지어내지 않는다.** 로컬 파일에 없는 정보(화성 위치라든가 대운 데이터 같은)가 필요한 질문이 오면, 아는 척 지어내는 대신 "아직 안 적혀있다"고 말하고 채워달라고 요청한다.
- **개인정보와 코드를 분리한다.** 페르소나·해석 규칙(`CLAUDE.md`)은 커밋되지만, 생년월일시·출생지·차트처럼 진짜 개인정보는 전부 gitignore된 `*.local.md` 파일에만 들어간다.

> 어디까지나 오락·자기 성찰용 도구다. 전문 상담이나 의사결정을 대신하진 않는다. 트랜짓 계산(`scripts/transits.py`) 자체는 실제 천문 계산(Swiss Ephemeris)이라 정확하지만, 그걸 심리적으로 어떻게 읽어내느냐는 상징체계의 영역이지 미래 예측이 아니다.

## 포크해서 쓰기

1. 이 레포를 포크하거나 클론한다.
2. `CLAUDE.md` 맨 위 첫 문장에 이름이 하나 박혀있는데, 그걸 자기 이름(또는 원하는 호칭)으로 바꾼다. 그 아래부터는 전부 "사용자"로 되어 있어서 따로 손댈 필요 없다.
3. 로컬 데이터 파일 세 개를 직접 채운다. Claude는 이 파일들을 대신 채우거나 추측으로 수정하지 않게 되어 있으니(`CLAUDE.md` 가드레일 참고), 실제 값은 본인이 직접 넣어야 한다.

| 파일 | 내용 | 채우는 방법 |
|---|---|---|
| `CLAUDE.local.md` | 현재 상황·성향·최근 관심사 | 자유롭게 적고, 상황이 바뀔 때마다 갱신 |
| `chart.local.md` | 서양 점성술 출생차트 (행성·하우스·어스펙트) | 생년월일시·출생지로 뽑은 차트 리딩 결과를 붙여넣기 |
| `saju.local.md` | 사주팔자 (원국·대운) | 사주 명식 계산 결과를 붙여넣기 |

세 파일 모두 `.gitignore`에 들어 있어서 커밋되지 않는다. 이름·생년월일시·출생지 같은 개인정보는 이 세 파일 밖(즉 커밋되는 파일)에는 절대 적지 말고, 혹시 실수로 들어갔다면 커밋하기 전에 꼭 지우자.

이 세 파일과 별개로 `journal.local/`(상담일지 폴더)도 gitignore돼 있는데, 이건 직접 채우는 파일이 아니라 "이거 상담일지에 남겨줘"라고 요청할 때마다 Claude가 세션마다 파일을 하나씩(`YYYY-MM-DD-주제.md`) 새로 만들어서 대화 내용을 요약해 남기는 곳이다. 여러 세션에 걸쳐 반복되는 감정/인지 패턴은 `journal.local/_patterns.md`에 별도로 누적된다. 자세한 기록 규칙은 `CLAUDE.md`의 "상담일지" 섹션 참고.

4. 트랜짓 계산기가 필요하면 설치한다 (선택 — 아래 참고).

## 사용법

Claude Code로 레포를 열고 그냥 자연어로 물어보면 된다 — "요즘 전반적인 흐름이 어때", "지금 수성 역행이야?", "이직하기 괜찮은 시기야?" 같은 식으로.

서양 점성술과 사주를 섞어서 절충하진 않는다:
- 사주는 기본적으로 답변에서 제외한다 — 사주 고유 개념이 꼭 필요하거나 사용자가 직접 물어봤을 때만 등장한다.
- 사주가 등장하는 경우, 질문이 한쪽 체계에만 해당하면 그 체계로만 답하고, 둘 다 걸리면 서양 점성술이 메인이고 사주는 짧게 덧붙는 정도로 비중을 낮춘다.
- 겹치는 테마가 있을 때만 "공명" 정도로 짧게 짚어준다 — 행성과 오행을 억지로 등치시키진 않는다.

답변 톤이나 세부 가드레일은 [`CLAUDE.md`](./CLAUDE.md)에 다 정의돼 있다. 이 파일을 고치면 페르소나를 원하는 대로 바꿀 수 있다.

## 트랜짓 계산기 (`scripts/transits.py`)

"언제쯤 ~할까" 같은 타이밍 질문에는 감이 아니라 실제 트랜짓 계산(Swiss Ephemeris)을 근거로 쓴다. 이 스크립트 자체엔 개인정보가 전혀 없다 — 특정 시각의 행성 좌표만 계산할 뿐이고, 원국 데이터는 실행할 때마다 `--natal`/`--cusps` 인자로 넘겨줄 뿐이라 그대로 커밋해도 괜찮다.

처음 한 번만 설치하면 된다:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r scripts/requirements.txt
```

사용 예시:

```bash
# 지금 이 순간 트랜짓 행성 위치 (수성 역행 여부 등)
python3 scripts/transits.py positions

# 트랜짓 행성이 원국의 특정 지점과 이루는 어스펙트
# 절대황경도 변환식: sign_index*30 + 도 + 분/60 (Aries=0 ... Pisces=11)
python3 scripts/transits.py aspects --natal "Venus=157.03,DSC=157.23" --orb 3
```

`--cusps`로 하우스까지 보거나 `--datetime`으로 특정 시각을 지정하는 등 더 자세한 옵션은 스크립트 상단 docstring과 `CLAUDE.md`의 "트랜짓 계산" 섹션에 정리해뒀다.

## 파일 구성

```
CLAUDE.md                  페르소나·운영 지침                          (커밋됨, 개인정보 없음)
CLAUDE.local.md            현재 상황·성향                              (gitignore, 직접 작성)
chart.local.md             서양 점성술 출생차트                        (gitignore, 직접 작성)
saju.local.md              사주팔자                                    (gitignore, 직접 작성)
journal.local/             상담 이력 폴더 (세션당 파일 1개 + _patterns.md 누적 패턴)  (gitignore, 요청 시 Claude가 기록)
scripts/transits.py        트랜짓 계산기                                (커밋됨, 개인정보 없음)
scripts/requirements.txt   트랜짓 계산기 의존성 (pyswisseph)
```
